# SeedTools Suite

SeedTools Suite is an **offline‑first, open‑source Bitcoin recovery and forensics toolkit**.  
It focuses on deterministic seed recovery, entropy diagnostics, BIP32/44/49/84/86 path exploration, Taproot forensics, and secure workflows for high‑risk users and NGOs.

---

## Features

- **Offline‑first design** — no network access required for core operations  
- **Deterministic seed recovery tools**  
- **Entropy diagnostics and sanity checks**  
- **BIP32/44/49/84/86 + Taproot path exploration**  
- **Address scanning (configurable ranges)**  
- **Forensics‑oriented workflows for NGOs and high‑risk users**  

---

## Use Cases

SeedTools is designed for:

- **activists and journalists** operating in hostile environments  
- **NGOs** handling Bitcoin donations and emergency funds  
- **users recovering wallets after device loss or corruption**  
- **technical operators** performing audits and forensics on Bitcoin setups  

---

## Security Model (High‑Level)

- core tools are designed to run **offline**  
- no telemetry, no external API calls in recovery workflows  
- deterministic operations with reproducible behavior  
- user keeps full control over keys, seeds, and data
