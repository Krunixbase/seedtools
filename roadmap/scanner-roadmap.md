# **Address Scanner — Roadmap**

The Address Scanner is the **verification and analysis engine** of the SeedTools Suite.  
Its mission is to provide **deterministic, offline‑first address validation**, derivation path inference, ownership matching, and batch verification — safe for NGOs, high‑risk users, and support teams.

---

# **1. High‑Level Vision**

The Address Scanner becomes:

- the **global standard** for deterministic Bitcoin address verification  
- the **fastest offline address analysis tool**  
- the **reference implementation** for derivation path inference  
- the **NGO‑ready batch verification engine**  
- the **bridge** between Recovery, Forensics, and Path Explorer  

---

# **2. 3‑Month Roadmap — Foundation Phase**





- **Address Parsing Engine v1**  
  Detect P2PKH, P2SH‑P2WPKH, P2WPKH, P2TR formats.

- **Derivation Path Inference MVP**  
  Infer BIP44/49/84/86 paths from address type.

- **Single Address Verification MVP**  
  Validate checksum, format, and type.

- **Batch Input MVP**  
  Paste multiple addresses at once.

- **Scanner UX v1**  
  Clean layout, warnings, validation states.

- **Documentation v1**  
  Architecture, examples, path inference logic.

---

# **3. 6‑Month Roadmap — Expansion Phase**





- **Batch Verification PRO**  
  Validate hundreds of addresses with deterministic performance.

- **Ownership Matching Engine**  
  Match addresses to derived keys from Recovery Tool.

- **Wallet Metadata Detection**  
  Detect Sparrow, Specter, Electrum, BTCPay patterns.

- **Taproot Path Inference**  
  Full BIP86 inference and validation.

- **Address Map Export v1**  
  Export address → path → type mappings.

- **UX Enhancements**  
  Better grouping, warnings, and visual indicators.

---

# **4. 12‑Month Roadmap — PRO Phase**





- **Scanner PRO Engine**  
  Multi‑account inference, mixed‑wallet detection, anomaly scoring.

- **Cross‑Tool Integration**  
  Recovery → Scanner → Forensics → Export workflows.

- **NGO Batch Verification Mode**  
  Field‑safe, minimal‑metadata, high‑speed verification.

- **Interoperability Layer**  
  Shared models with Recovery, Forensics, Path Explorer.

- **Reproducible Builds**  
  Deterministic binaries + verification instructions.

- **Scanner PRO Dashboard**  
  Address clusters, path trees, ownership maps.
