# **Suite Launcher — Roadmap**

The Suite Launcher is the **central entry point** of the entire SeedTools ecosystem.  
Its mission is to provide a unified, secure, preset‑aware, offline‑first navigation and workflow orchestration layer for all SeedTools applications.

This roadmap defines the next 12 months of development.

---

# **1. High‑Level Vision**

The Launcher becomes:

- the **single point of entry** for all SeedTools tools  
- the **preset brain** of the Suite  
- the **workflow orchestrator** for multi‑tool operations  
- the **security gatekeeper** (Hardened Mode, NGO Mode)  
- the **cross‑app session manager**  

---

# **2. 3‑Month Roadmap — Foundation Phase**

- **Launcher Core Engine v1**  
  Unified navigation, offline‑first architecture, deterministic app loading.

- **Preset Manager v1**  
  BIP presets, wallet presets, NGO presets.

- **Guided Workflows MVP**  
  Recovery Mode, Forensics Mode, Address Verification Mode.

- **Launcher UX v1**  
  Clean layout, secure input components, consistent UI across apps.

- **Suite‑Wide Settings**  
  Theme, language, offline mode, hardened mode toggle.

- **Documentation Hub MVP**  
  Central access to all READMEs and offline manuals.

---

# **3. 6‑Month Roadmap — Expansion Phase**

- **Cross‑App Session Sync**  
  Share mnemonic, entropy, and path context across apps without re‑entering.

- **Guided Recovery PRO**  
  Multi‑step recovery with automatic tool chaining.

- **Wallet Preset Auto‑Detection**  
  Detect wallet type from mnemonic, xpub, or address.

- **Launcher Notifications**  
  Progress indicators, warnings, cross‑app alerts.

- **Suite‑Wide Export Module**  
  Export reports, paths, diagnostics, and session summaries.

- **UX Enhancements**  
  Smoother navigation, improved layout, accessibility improvements.

---

# **4. 12‑Month Roadmap — PRO Phase**

- **Hardened Mode PRO**  
  Zero‑trace execution, no disk writes, secure memory handling.

- **Cross‑App Automation Engine**  
  Automatic multi‑tool workflows (e.g., Forensics → Recovery → Export).

- **Suite‑Wide Interoperability Layer**  
  Shared engines, shared presets, unified data formats.

- **Mixed‑Wallet Detection**  
  Detect wallets using multiple BIP standards.

- **Launcher PRO Dashboard**  
  Advanced analytics, session summaries, forensic indicators.

- **Reproducible Builds**  
  Deterministic builds + verification instructions.

---

# **5. Strategic Themes**

- **Security** — hardened mode, zero‑trace execution, offline‑first  
- **Interoperability** — shared presets, cross‑app session sync  
- **Automation** — multi‑tool workflows, CLI integration  
- **Accessibility** — guided workflows, NGO presets, clean UX  
- **Determinism** — reproducible builds, deterministic outputs  

---

# **6. Long‑Term Vision**

The Suite Launcher becomes the **central nervous system** of SeedTools:

- unified UX across all apps  
- trusted by NGOs and support teams  
- safe for high‑risk users  
- fully offline and auditable  
- reproducible and verifiable  
- the default entry point for deterministic Bitcoin recovery and forensics
