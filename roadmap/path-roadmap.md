# **Path Explorer — Roadmap**

The Path Explorer is the **deterministic derivation path analysis engine** of the SeedTools Suite.  
Its mission is to provide **offline‑first path validation**, BIP standard detection, key derivation, address generation, and advanced path forensics — essential for Recovery, Forensics, and Scanner workflows.

---

# **1. High‑Level Vision**

The Path Explorer becomes:

- the **global reference implementation** for BIP32/44/49/84/86 path logic  
- the **safest offline path analysis tool**  
- the **core engine** powering Recovery, Scanner, and Desktop  
- the **educational tool** for understanding hierarchical deterministic wallets  
- the **NGO‑ready verifier** for compromised or unknown wallet structures  

---

# **2. 3‑Month Roadmap — Foundation Phase**

- **Path Validation Engine v1**  
  Syntax validation, hardened markers, index parsing, error detection.

- **BIP Standard Detection MVP**  
  Detect BIP44, BIP49, BIP84, BIP86 based on path structure.

- **Key Derivation MVP**  
  Deterministic BIP32 derivation for any valid path.

- **Address Generation MVP**  
  P2PKH, P2WPKH, P2TR address generation from derived keys.

- **Path Metadata Engine**  
  Depth, hardened segments, account/index extraction.

- **Documentation v1**  
  BIP32 theory, path structure, examples.

---

# **3. 6‑Month Roadmap — Expansion Phase**

- **Advanced Path Forensics**  
  Detect anomalies, non‑standard paths, mixed‑wallet structures.

- **Multi‑Account Path Detection**  
  Identify multiple accounts within a wallet.

- **Taproot Path Support (BIP86)**  
  Full P2TR path validation and derivation.

- **Path Explorer UX Enhancements**  
  Visual path trees, warnings, educational tooltips.

- **Export Module v1**  
  Path summaries, key metadata, address previews.

- **Integration with Scanner**  
  Infer paths from addresses and validate them.

---

# **4. 12‑Month Roadmap — PRO Phase**

- **Path Explorer PRO**  
  Full anomaly scoring, mixed‑wallet detection, path heuristics.

- **Compromised Wallet Workflow**  
  Safe workflows for unknown, tampered, or partially known paths.

- **NGO‑Friendly Path Reports**  
  Printable, minimal‑metadata, field‑safe summaries.

- **Interoperability Layer**  
  Shared path models across Recovery, Forensics, Scanner, Desktop.

- **Cross‑Tool Automation**  
  Recovery → Path Explorer → Scanner → Export workflows.

- **Reproducible Builds**  
  Deterministic binaries + verification instructions.

---

The Path Explorer becomes:
