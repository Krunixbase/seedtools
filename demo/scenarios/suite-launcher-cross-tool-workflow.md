# Scenario: Cross‑Tool Workflow Using Suite Launcher

## Overview
Demonstrates how multiple tools work together through the Suite Launcher.

## Input
- Mnemonic  
- Known addresses  
- Unknown derivation path  
- Suspected corruption

## Steps
1. Open **Suite Launcher**
2. Select **Full Recovery Workflow**
3. Automatic sequence:
   - Mnemonic validation  
   - Entropy inspection  
   - Path exploration  
   - Address scanning  
   - Forensics analysis  
4. Review final report

## Expected Output
- Full recovery report  
- Path inference  
- Drift detection  
- Forensics summary  
- Recommended next steps
