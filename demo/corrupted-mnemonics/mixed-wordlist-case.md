# Corrupted Mnemonic: Mixed Wordlist Case

## Description
Mnemonic contains words from multiple BIP39 language lists (e.g., English + Spanish).

## Example
```
abandon ability able sobre above absent absorb abstract absurd abuse access accident
```

## Symptoms
- Mnemonic appears partially valid  
- Wordlist mismatch  
- Checksum cannot be computed  

## Tools Used
- Mnemonic Tools — Wordlist Validator  
- Forensics Tool — Language Detection
