# Corrupted Mnemonic: Missing Words

## Description
A 12‑word mnemonic with 2 missing words.  
Checksum is unknown.  
User only remembers approximate positions.

## Example
```
abandon abandon ? ? abandon abandon abandon abandon abandon abandon abandon about
```

## Symptoms
- Cannot import into wallet  
- Checksum mismatch  
- Multiple valid candidates possible  

## Tools Used
- Mnemonic Tools — Missing Word Recovery  
- Address Scanner — Match Known Addresses
