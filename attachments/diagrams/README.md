# Diagrams

This folder contains all architectural, workflow, and system diagrams used across the SeedTools Suite documentation.

## Structure
- **architecture/** — system architecture diagrams
- **data-flow/** — data flow and processing diagrams
- **module-map/** — module structure and relationships
- **compliance/** — compliance suite diagrams
- **recovery/** — recovery pipeline and audit trail
- **ngo/** — NGO workflows and compliance pipelines

## Purpose
These diagrams are used in:
- technical documentation
- grant applications
- pitch deck
- internal planning
