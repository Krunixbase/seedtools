# 🎨 **SeedTools Color Palette**

## 1. **Overview**
The SeedTools color palette is designed to reflect the project’s core values: **security, clarity, determinism, and technical precision**.  
Colors are minimal, functional, and optimized for both light and dark environments.

This document defines:

- primary colors  
- accent colors  
- neutral colors  
- usage rules  

---

## 2. **Primary Colors**

### **Primary Blue**
- **Hex:** `#0A1A2F`  
- **Role:** Main brand color  
- **Usage:** Logotype, headers, UI elements, dark backgrounds  

### **Accent Blue**
- **Hex:** `#1F4FFF`  
- **Role:** Highlight color  
- **Usage:** Links, active states, emphasis, interactive elements  

---

## 3. **Neutral Colors**

### **White**
- **Hex:** `#FFFFFF`  
- **Usage:** Light backgrounds, light-mode UI, contrast for dark logo  

### **Black**
- **Hex:** `#000000`  
- **Usage:** Monochrome logo, print materials, high‑contrast elements  

---

## 4. **Extended Palette (Optional)**

### **Navy Background**
- **Hex:** `#0D1220`  
- **Usage:** Dark splash screens, hero sections, high‑contrast layouts  

### **Soft Gray**
- **Hex:** `#E6E8EC`  
- **Usage:** Dividers, subtle backgrounds, documentation UI  

---

## 5. **Usage Guidelines**

### 5.1 Background Rules
- Use **Primary Blue** or **Navy** for dark‑mode layouts  
- Use **White** for light‑mode layouts  
- Use **Accent Blue** sparingly to avoid visual noise  

### 5.2 Logo Compatibility
- **Light logo** → dark backgrounds (`#0A1A2F`, `#0D1220`, black)  
- **Dark logo** → light backgrounds (`#FFFFFF`, soft gray)  
- **Mono logo** → print or grayscale environments  

### 5.3 Accessibility
- Maintain a minimum contrast ratio of **4.5:1** for text  
- Avoid placing Accent Blue on dark backgrounds without increasing brightness
