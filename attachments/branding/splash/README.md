# SeedTools Splash Screens

The [splash/](/attachments/branding/splash/) directory contains all **splash screen assets** used across SeedTools Suite.  
Splash screens define the **first visual impression** of the toolkit — clean, deterministic, neon‑driven, and offline‑safe.

They are used in:

- documentation  
- pitch decks  
- UI previews  
- branding announcements  
- PRO/Enterprise visuals  
- social media posts  

Splash screens are designed to be **minimal**, **high‑contrast**, and **instantly recognizable**.

## Usage Guidelines

### 1. Light Splash (`splash-light.png` / `splash-light.svg`)
Use for:

- documentation  
- pitch decks  
- light UI previews  
- white or soft‑gray backgrounds  

### 2. Special Icon Splash (`splash-special-icon.png`)
Use for:

- social media posts  
- branding announcements  
- hero sections  
- PRO/Enterprise visuals  
- high‑impact presentations  

### 3. Dark Splash (`splash-dark.svg`)
Use for:

- dark UI previews  
- neon‑accent layouts  
- high‑contrast branding materials

## Contribution Rules

When adding new splash screens:

- follow the SeedTools neon palette  
- maintain minimal, deterministic layout  
- include both PNG + SVG versions  
- avoid gradients, shadows, or stylistic noise  
- update this README when adding new files
