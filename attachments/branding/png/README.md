# SeedTools PNG Assets

The `png/` directory contains all **raster branding assets** for SeedTools Suite.  
PNG files are optimized for:

- documentation  
- pitch decks  
- UI previews  
- screenshots  
- social media  
- environments where SVG is not supported  

PNG assets provide **pixel‑perfect clarity**, consistent sizing, and reliable rendering across all platforms.

## Files Included

### Icons (PNG)

- `seedtools-icon-128.png` — 128×128 px  
- `seedtools-icon-256.png` — 256×256 px  
- `seedtools-icon-512.png` — 512×512 px  
- `seedtools-icon-1024.png` — 1024×1024 px  

These sizes are ideal for:

- app icons  
- UI previews  
- documentation headers  
- social media posts

### Logos (PNG)

- `seedtools-logo-dark.png` — for light backgrounds  
- `seedtools-logo-light.png` — for dark backgrounds  
- `seedtools-logo-mono.png` — monochrome variant  
- `seedtools-logo-tagline.png` — logo with tagline  

Use cases:

- pitch decks  
- documentation

## Usage Guidelines

### Background Compatibility

- **logo-light.png** → dark backgrounds  
- **logo-dark.png** → light backgrounds  
- **logo-mono.png** → grayscale, print, or minimal UI  
- **logo-tagline.png** → hero sections, pitch decks, splash previews

## Contribution Rules

When adding new PNG assets:

- export from the master SVG source  
- maintain consistent padding and safe‑areas  
- avoid compression artifacts  
- include multiple resolutions (128–1024 px)  
- update this README when adding new files
