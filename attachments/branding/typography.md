# ✍️ **SeedTools Typography**

## 1. **Overview**
Typography in SeedTools reflects the project’s core values: **clarity, precision, and technical reliability**.  
The type system is minimal, readable, and optimized for both documentation and UI.

This document defines:

- primary fonts  
- usage rules  
- hierarchy  
- code formatting  
- accessibility guidelines  

---

## 2. **Primary Fonts**

### **Inter**
- Clean, modern sans‑serif  
- Optimized for UI and long‑form reading  
- Used for: body text, documentation, UI labels

- High‑legibility monospaced font  
- Designed for developers

## 3. **Font Usage Rules**

### 3.1 **Primary Usage**
| Element | Font | Weight | Notes |
|--------|-------|---------|--------|
| Body text | Inter | Regular (400) | Default for documentation |
| Headings | Inter / IBM Plex Sans | 500–700 | Use consistent hierarchy |
| Code | JetBrains Mono | Regular (400) | No ligatures in examples |
| UI labels | Inter | Medium (500) | Buttons, menus, tooltips |

---

## 4. **Typography Hierarchy**

### **H1 — Page Titles**
- Font: Inter / IBM Plex Sans  
- Weight: 700  
- Size: 32–40 px  
- Usage: main section titles  

### **H2 — Section Headers**
- Font: Inter  
- Weight: 600  
- Size: 24–28 px  

### **H3 — Subsections**
- Font: Inter  
- Weight: 500  
- Size: 18–20 px  

### **Body Text**
- Font: Inter  
- Weight: 400  
- Size: 15–16 px  
- Line height: 1.5–1.65  

### **Code Blocks**
- Font: JetBrains Mono  
- Size: 14–15 px  
- Line height: 1.4  

---

## 5. **Code Formatting**

### Inline Code
Use JetBrains Mono for inline code:

```
`seedtools recover --path /wallet`
```

### Code Blocks
Use fenced blocks with syntax highlighting:

```
seedtools recover --input seed.txt --output wallet.json
```

## 6. **Accessibility Guidelines**
To ensure readability:

- Maintain a minimum contrast ratio of **4.5:1**  
- Avoid using Accent Blue for long text  
- Use Inter Regular for paragraphs (not Light)  
- Use JetBrains Mono only for code, never for UI paragraphs
