# SeedTools SVG Assets

The `svg/` directory contains all **vector‑based branding assets** for SeedTools Suite.  
These files are used for:

- high‑resolution UI  
- splash screens  
- documentation  
- pitch decks  
- print materials  
- deterministic scaling in offline environments  

SVG files are **resolution‑independent**, lightweight, and ideal for security‑critical UI where clarity and precision matter.

## Files Included

### Logos

- `seedtools-logo-master.svg` — full master logo (symbol + logotype)  
- `seedtools-logo-dark.svg` — logo for light backgrounds  
- `seedtools-logo-light.svg` — logo for dark backgrounds  
- `seedtools-logo-mono.svg` — monochrome variant (`currentColor`)  
- `seedtools-logo-tagline.svg` — logo with tagline  
- `seedtools-logo-special.svg` — special neon variant  
- `seedtools-logo-symbol.svg` — symbol only (hex‑node network)

### Icon

- `seedtools-icon.svg` — main SeedTools icon (hex‑node network)

### Splash Screens (SVG)

- `splash-light.svg` — light splash screen  
- `splash-dark.svg` — dark splash screen  

---

## Usage Guidelines

### Background Compatibility

- use **logo-light** on dark backgrounds  
- use **logo-dark** on light backgrounds  
- use **logo-mono** for grayscale, print, or `currentColor` UI  
- use **logo-symbol** for favicons, badges, compact UI elements

## Contribution Rules

When adding new SVG assets:

- follow the SeedTools neon palette  
- maintain consistent stroke width  
- avoid gradients, shadows, and effects  
- keep filenames deterministic and lowercase  
- update this README when adding new files
