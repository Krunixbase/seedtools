# **SeedTools SVG Assets**

The **svg/** directory contains all **vector‑based branding assets** for SeedTools Suite.  
These files are used for:

- high‑resolution UI  
- splash screens  
- documentation  
- pitch decks  
- print materials  
- deterministic scaling in offline environments  

SVG files are **resolution‑independent**, **lightweight**, and **ideal for security‑critical UI**, where clarity and precision matter.

## **Usage Guidelines**

### **1. Background Compatibility**
- Use **logo-light.svg** on dark backgrounds  
- Use **logo-dark.svg** on light backgrounds  
- Use **logo-mono.svg** for grayscale, print, or UI currentColor contexts  
- Use **logo-symbol.svg** for favicons, badges, and compact UI elements  

---

### **2. Deterministic Rendering**
SVG files are optimized for:

- offline rendering  
- deterministic scaling  
- zero raster artifacts  
- consistent stroke widths  
- predictable geometry  

This ensures SeedTools branding looks identical across all environments.

---

### **3. Recommended Use Cases**
- documentation (`docs/`)  
- pitch decks (`attachments/pitch-deck/`)  
- splash screens  
- UI previews  
- enterprise compliance documents  
- marketing materials

## **Contribution Rules**

When adding new SVG assets:

- follow the SeedTools neon palette  
- maintain consistent stroke width  
- avoid gradients, shadows, or effects  
- keep filenames deterministic and lowercase  
- update this README when adding new files
