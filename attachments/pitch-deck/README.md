# SeedTools Pitch Deck

The [attachments/pitch-deck/](/attachments/pitch-deck/) directory contains all **presentation materials** used to introduce SeedTools Suite in a clear, professional, and deterministic way.  
These slides are designed for:

- grant applications  
- investor presentations  
- security audits  
- enterprise onboarding  
- technical briefings  
- conference submissions  

Pitch deck materials follow the same branding rules as the rest of SeedTools:  
**minimal, neon‑driven, offline‑safe, and consistent.**

## Design Guidelines

### 1. Layout
- minimal  
- high contrast  
- plenty of whitespace  
- deterministic spacing  
- consistent margins  

### 2. Colors
Use the official palette:

- dark backgrounds → `#0A1A2F` / `#0D1220`  
- light backgrounds → `#FFFFFF` / soft gray  
- neon accent → **#00FF88** (sparingly)

Reference:  
- [Color Palette](/attachments/branding/colors.md)

### 3. Typography
- Inter → headings + body  
- JetBrains Mono → code  
- IBM Plex Sans → optional hero sections  

Reference:  
- [Typography Rules](/attachments/branding/typography.md)

### 4. Logo Usage
- dark logo → light slides  
- light logo → dark slides  
- mono logo → grayscale or print  
- symbol mark → compact sections  

Reference:  
- [Brandbook](/attachments/branding/guidelines/brandbook.md)

## Recommended Slide Structure

A typical SeedTools pitch deck includes:

1. **Cover Slide**  
   - splash  
   - logo  
   - tagline  

2. **Problem Statement**  
   - offline recovery  
   - deterministic tools  
   - high‑risk environments  

3. **SeedTools Overview**  
   - modules  
   - workflows  
   - offline guarantees  

4. **Branding & Identity**  
   - neon identity  
   - deterministic UI  
   - security‑first design  

5. **Technical Architecture**  
   - diagrams  
   - entropy flow  
   - checksum logic  

6. **Use Cases**  
   - auditors  
   - technicians  
   - security teams  

7. **Roadmap / Grants**  
   - milestones  
   - funding goals

## Contribution Rules

When adding new pitch‑deck materials:

- follow SeedTools branding rules  
- use SVG assets for logos  
- use PNG assets for screenshots  
- maintain deterministic spacing  
- avoid gradients, shadows, or stylistic noise  
- update this README when structure changes
