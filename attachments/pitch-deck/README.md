# Pitch Deck Assets

This folder contains all visual and presentation assets used in the SeedTools Suite pitch deck.

## Structure
- **slides/** — exported slide images (PNG/JPG)
- **diagrams/** — high‑resolution diagrams used in the deck
- **exports/** — final PDF versions of the pitch deck

## Purpose
These assets are used for:
- grant applications (OpenSats, HRF, Spiral, BTCPay)
- investor presentations
- public documentation
- conference materials
