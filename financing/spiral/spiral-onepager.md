# **SeedTools 2.0 — One‑Pager (Spiral Edition)**

## **What is SeedTools?**
SeedTools 2.0 is an **offline, open‑source toolkit** for deterministic Bitcoin wallet recovery and forensic analysis.
It helps users recover HD wallets, analyze corrupted mnemonics, verify derivation paths, and validate addresses — all without exposing private data or relying on third parties.

SeedTools is designed as a **public good** for the Bitcoin ecosystem: transparent, auditable, offline‑first, and MIT‑licensed.

---

## **Why It Matters**
Self‑custody is a cornerstone of Bitcoin, but recovery is fragile.
Users lose access to funds due to:

- corrupted or incomplete mnemonics
- wrong derivation paths
- missing passphrases
- misconfigured wallet setups
- compromised or confiscated devices

Today, the ecosystem lacks a unified, well‑maintained, offline‑first recovery toolkit.

SeedTools fills this gap by providing deterministic, transparent, reproducible workflows that strengthen Bitcoin’s self‑custody layer.

---

## **Key Features**

- deterministic HD wallet recovery
- deep derivation path scanning (0 → X)
- BIP44/49/84/86 + Taproot
- corrupted mnemonic analysis
- entropy validation
- forensic reports
- Safe Mode for high‑risk users
- CLI for Tails/Qubes
- fully offline (no telemetry, no API calls)

## **Long‑Term Vision**

SeedTools aims to become the **standard offline recovery and forensics toolkit** for Bitcoin — a neutral, open, well‑maintained project that:

- reduces permanent loss of funds,
- improves wallet interoperability,
- supports high‑risk users,
- strengthens self‑custody education,
- provides reproducible, auditable recovery logic.
