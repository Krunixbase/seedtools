# **SeedTools 2.0 — Roadmap (Spiral Edition)**

## **Overview**

This roadmap outlines the development of SeedTools 2.0 over an 18‑month period.
It focuses on:

- deterministic recovery,
- forensic tooling,
- reproducible builds,
- wallet interoperability,
- NGO‑friendly workflows,
- long‑term maintenance.

All work is open‑source under MIT License.

---

# **1. 3‑Month Roadmap — Foundation Phase**

## **1.1 Deterministic Engine v1**
- BIP32/39/44/49/84/86
- deep derivation path scanning (0 → X)
- deterministic address verification
- architecture stabilization

## **1.2 Recovery Mode MVP**
- guided recovery workflows
- passphrase handling
- multi‑wallet compatibility (Sparrow, Electrum, Specter)
- address verification

## **1.3 Forensics Mode MVP**
- corrupted mnemonic detection
- entropy validation
- checksum repair suggestions

## **1.4 Documentation v1**
- architecture docs
- basic recovery workflows
- initial demo pack
