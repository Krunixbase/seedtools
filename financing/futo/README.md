## 📁 FUTO — Funding Package

This folder contains documentation related to funding applications prepared for **FUTO (Freedom From The Unfreedom To Operate)**.

FUTO supports open-source projects focused on user freedom, privacy, transparency, ownership, and independence from centralized platforms.

SeedTools Suite aligns with these principles through its offline-first architecture, deterministic workflows, transparent security model, reproducible builds, and commitment to open-source development.

### 📄 Included Documents

- **FUTO Application** — primary funding application
- **FUTO One-Pager** — concise project summary
- **FUTO Progress Report** — progress since previous application
- **FUTO Roadmap** — development goals and milestones
- **FUTO Impact Statement** — user freedom, privacy, and security impact

Each document may be submitted independently or as part of a complete funding package.

### 🎯 Purpose of This Package

The FUTO funding package is designed to:

- present SeedTools Suite as a user-sovereignty and security project
- demonstrate commitment to open-source transparency
- showcase deterministic and reproducible security tooling
- document project progress across development milestones
- provide a structured package for future grant submissions

### 🧭 Alignment With FUTO Principles

SeedTools Suite promotes:

- user ownership and self-custody
- offline-first workflows
- privacy-preserving operation
- transparent and auditable algorithms
- deterministic security tooling
- reproducible builds
- freedom from centralized services
