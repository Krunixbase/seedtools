## **FUTO Reapplication Plan — SeedTools Suite**

### Purpose

This document defines the strategy for a future FUTO grant reapplication.

The previous application established initial contact with FUTO and introduced SeedTools as an open-source security project.

A future submission should focus on demonstrating measurable progress, project maturity, and stronger alignment with FUTO's principles of user freedom, transparency, ownership, and independence from centralized systems.

Initial application submitted:

- October 2026
- Project Name: SeedTools Enterprise
- Focus: Open Source Security Toolkit
