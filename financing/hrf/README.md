# **📁 HRF — Human Rights Foundation Funding Package**

This folder contains the complete grant package prepared for the **Human Rights Foundation — Bitcoin Development Fund**.  
All documents follow HRF’s expectations for clarity, structure, and human‑rights‑focused impact.

SeedTools Suite is an offline‑first, open‑source Bitcoin recovery and forensics toolkit designed for NGOs, activists, journalists, and high‑risk users operating in hostile environments.

---

## **📄 Included Documents**

- **HRF Application** — main grant application  
- **HRF One‑Pager** — concise project summary  
- **HRF Budget** — microgrant budget  
- **HRF Impact Statement** — human‑rights impact analysis  

Each document is standalone and can be submitted independently or as a complete package.

---

## **🎯 Purpose of This Package**

The HRF funding package is designed to:

- present SeedTools Suite as a **human‑rights‑aligned security tool**  
- demonstrate its relevance for **high‑risk users and NGOs**  
- show technical readiness and clear development direction  
- provide HRF reviewers with a **clean, structured, transparent** set of materials  
- maximize the project’s chances of receiving funding
