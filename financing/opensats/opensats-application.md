# **SeedTools 2.0 — OpenSats Grant Application**

## **1. Project Name**
**SeedTools 2.0 — Offline HD Wallet Recovery & Forensics Toolkit**

---

## **2. Project Summary (1–3 sentences)**
SeedTools 2.0 is an offline, open‑source toolkit for recovering Bitcoin HD wallets, analyzing corrupted backups, scanning BIP paths, and verifying addresses.
It is designed for high‑risk users, activists, journalists, and NGOs who need secure, private, air‑gapped wallet recovery tools.
The project strengthens Bitcoin self‑custody by providing deterministic, transparent, offline‑first recovery workflows.

---

## **3. Problem Statement**
Millions of Bitcoin users rely on mnemonic backups, but many lose access due to:

- incorrect derivation paths
- corrupted mnemonics
- missing passphrases
- wrong wallet formats
- outdated or incompatible software
- compromised devices
- lack of offline tools

Existing tools are fragmented, outdated, or require online components.
There is **no unified, offline‑first, open‑source toolkit** for deterministic wallet recovery and forensic analysis.

SeedTools fills this gap.

---

## **4. Proposed Solution**
SeedTools 2.0 provides:

- deterministic HD wallet recovery
- deep derivation path scanning (0 → X)
- BIP44/49/84/86 + Taproot support
- mnemonic integrity & repair tools
- address verification
- forensics mode for compromised devices
- GUI + CLI + Core modules
- fully offline workflows (no telemetry, no API calls)

The toolkit is designed to be safe for activists, journalists, and users in hostile environments.

---

## **5. Why This Matters for Bitcoin**
SeedTools strengthens Bitcoin self‑custody by:

- reducing permanent loss of funds
- enabling safe recovery without trusted third parties
- supporting high‑risk users in authoritarian regions
- improving wallet interoperability
- providing transparent, auditable recovery logic
- enabling NGOs to assist users without exposing private data

Self‑custody is a pillar of Bitcoin — SeedTools directly reinforces it.
