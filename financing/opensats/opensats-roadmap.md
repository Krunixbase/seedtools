# **SeedTools 2.0 — Roadmap (OpenSats)**

## **Overview**
This roadmap outlines the development of SeedTools 2.0 over a 12‑month period, focusing on offline HD wallet recovery, forensics, deterministic scanning, and secure workflows for high‑risk users.

The plan is divided into:

- **3‑month milestones**
- **6‑month milestones**
- **12‑month milestones**

All work is open‑source under MIT License.

---

# **1. 3‑Month Roadmap (MVP Phase)**

## **1.1 Recovery Mode MVP**
- deterministic HD wallet recovery
- BIP44/49/84/86 scanning
- deep path scanning (0 → 100 500)
- address verification
- passphrase handling
- multi‑wallet compatibility (Sparrow, Electrum, BlueWallet)

## **1.2 Forensics Mode MVP**
- corrupted mnemonic detection
- entropy validation
- checksum repair suggestions
- compromised device workflow (offline‑first)

## **1.3 CLI v1**
- offline CLI for Tails/Qubes
- deterministic engine integration
- reproducible build setup (initial)

## **1.4 Documentation v1**
- architecture
- recovery workflows
- forensics workflows
- demo pack

---

# **2. 6‑Month Roadmap (Core Expansion)**

## **2.1 Taproot Support**
- BIP86 scanning
- xprv/tprv compatibility
- address verification
- Taproot forensic tools

## **2.2 Safe Mode for Activists**
- hardened offline workflows
- no‑disk‑write mode
- secure session memory handling
- threat‑model documentation

## **2.3 GUI Enhancements**
- dark mode
- improved navigation
- error handling
- onboarding screens

## **2.4 Installer (.exe)**
- Windows installer
- icon + branding
- splash screen
- offline packaging

## **2.5 Reproducible Builds**
- deterministic build pipeline
- verification instructions

# **4. Long‑Term Vision**
SeedTools aims to become the **standard offline recovery toolkit** for:

- activists
- journalists
- NGOs
- self‑custody beginners
- advanced users
- educators

The project will remain fully open‑source, offline‑first, and MIT‑licensed.
