# **Budget Breakdown — SeedTools Suite**

SeedTools Suite requests funding to support **12 months of development**, security hardening, reproducible builds, NGO‑ready workflows, and long‑term maintenance of the deterministic recovery and forensics ecosystem.

The budget is structured around **modules**, **security**, **documentation**, and **infrastructure**, aligned with the roadmap deliverables.

# **2. Core Development (42,000 USD)**

This covers all deterministic engines and modules defined in the `applications/` folder.

### **Breakdown by module**

- **Recovery Tool** — $10,000  
  Deterministic reconstruction, path inference, scanning.

- **Forensics Tool** — $8,000  
  Entropy drift detection, corruption mapping, anomaly scoring.

- **Entropy Inspector** — $5,000  
  Bit‑level entropy analysis, checksum extraction.

- **Mnemonic Tools** — $4,000  
  Validation, reconstruction, entropy conversion.

- **Path Explorer** — $5,000  
  BIP32/44/49/84/86 path analysis and forensics.

- **Address Scanner** — $5,000  
  Batch verification, type detection, path inference.

- **Shared Engines & Utils** — $5,000  
  Validation, encoding, secure buffers, deterministic workflows.
