# **SeedTools 2.0 — One‑Pager (BTCPay Edition)**

## **What is SeedTools?**
SeedTools 2.0 is an **offline, open‑source toolkit** that helps merchants and self‑custody users safely recover Bitcoin wallets, verify derivation paths, analyze corrupted backups, and validate addresses — all without exposing private data.

It is designed for BTCPay Server users who rely on deterministic wallet structures and secure backups.

---

## **Why It Matters for BTCPay Merchants**

Merchants using BTCPay depend on:

- correct derivation paths
- reliable backups
- deterministic wallet structures
- safe recovery workflows

SeedTools provides:

- **BTCPay‑compatible derivation path presets**
- **deterministic address verification**
- **offline recovery workflows**
- **forensics for corrupted or misconfigured setups**

This reduces the risk of permanent fund loss and improves operational security.

---

## **Key Features**

- deterministic HD wallet recovery
- BIP44/49/84/86 + Taproot
- deep derivation path scanning (0 → X)
- corrupted mnemonic analysis
- address verification
- BTCPay merchant presets
- CLI for Tails/Qubes
- fully offline (no telemetry)
