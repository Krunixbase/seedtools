# Financing Overview — SeedTools Suite

This folder contains all grant‑related documentation for the SeedTools Suite project.  
It is structured by grant provider and includes applications, one‑pagers, budgets, impact statements, and integration plans.

SeedTools Suite is an offline‑first, open‑source Bitcoin recovery and forensics toolkit designed for NGOs, activists, journalists, and high‑risk users.

## Purpose of This Folder

This folder serves as:

- a **centralized hub** for all grant‑related materials  
- a **reference point** for reviewers and contributors  
- a **transparent record** of funding efforts  
- a **professional package** for organizations evaluating SeedTools  

---

## Funding Goals

Grant funding supports:

- deterministic recovery engine v2  
- NGO‑ready offline workflows  
- Safe Mode for high‑risk users  
- desktop GUI (offline, auditable)  
- extended Taproot forensics  
- reproducible builds v2  
- independent security review
