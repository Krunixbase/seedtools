# Rendering Engine — SeedTools Suite

The Rendering Engine provides deterministic, offline-only output rendering.

---

## 1. Design Goals

- no external assets  
- no fonts, scripts, or remote resources  
- reproducible rendering  
- hardened-mode compatibility  

---

## 2. Rendering Pipeline

```
Core Output → Renderer → Masking Layer → UI
```

---

## 3. Features

- masked rendering  
- deterministic layout  
- zero dynamic content
