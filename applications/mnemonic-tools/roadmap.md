# **Mnemonic Tools — Roadmap**

## **Overview**

This roadmap defines the development plan for Mnemonic Tools over the next 12 months.  
The focus is on secure mnemonic generation, validation, entropy conversion, passphrase diagnostics, educational tooling, and integration with Entropy Inspector and Forensics Tool.

---

# **1. 3‑Month Roadmap — Foundation Phase**

- **Mnemonic Generator v1** — secure offline generation for 12/15/18/21/24‑word mnemonics  
- **Mnemonic Validator MVP** — checksum validation, wordlist conformity, invalid‑word detection  
- **Entropy Conversion Engine** — mnemonic → entropy, entropy → mnemonic, checksum reconstruction  
- **Passphrase Tools MVP** — detect incorrect passphrases, show seed differences  
- **Wordlist Tools v1** — search, similarity detection, transcription‑error hints  
- **Documentation v1** — workflows, examples, architecture  

---

# **2. 6‑Month Roadmap — Expansion Phase**

- **Mnemonic Reconstruction Assistant** — assist users with missing or corrupted words  
- **Advanced Similar‑Word Detection** — detect visually or phonetically similar words  
- **Entropy Drift Visualizer** — highlight drifted entropy bits and checksum mismatches  
- **Taproot‑Specific Mnemonic Checks** — BIP86‑related mnemonic validation  
- **UX Enhancements** — clearer warnings, educational explanations, improved layout  
- **Export Module** — export mnemonic/entropy reports for NGOs/support teams  

---

# **3. 12‑Month Roadmap — PRO Phase**

- **Mnemonic Tools PRO** — full reconstruction engine, drift scoring, anomaly classification  
- **Compromised Backup Workflow** — safe workflows for tampered or partially destroyed backups  
- **NGO‑Friendly Reports** — printable, minimal‑metadata, field‑safe reports  
- **Interoperability Layer** — compatibility with wallet metadata formats  
- **Integration with Entropy Inspector** — automatic entropy diagnostics during mnemonic validation  
- **Reproducible Builds** — deterministic builds + verification instructions  

---

# **Long‑Term Vision**

Mnemonic Tools becomes the **standard offline mnemonic toolkit** for Bitcoin:

- trusted by NGOs and support teams  
- used by wallet developers to validate BIP39 implementations  
- safe for high‑risk users  
- fully auditable and reproducible  
- maintained as a long‑term public good
