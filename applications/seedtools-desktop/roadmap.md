# **SeedTools Desktop — Roadmap**

## **Overview**

This roadmap defines the development plan for SeedTools Desktop over the next 12 months.  
The focus is on unified UX, hardened security modes, cross‑app automation, wallet preset intelligence, reproducible builds, and deep integration across the entire Suite.

---

# **1. 3‑Month Roadmap — Foundation Phase**

- **Desktop Core Engine v1** — unified window manager, offline‑first architecture, secure app loading  
- **Integrated Tools MVP** — Recovery Tool, Forensics Tool, Address Scanner, Mnemonic Tools, Path Explorer  
- **Guided Workflows MVP** — Recovery Mode, Forensics Mode, Address Verification Mode  
- **Preset Manager v1** — BIP standards, wallet presets, NGO presets  
- **Documentation Hub MVP** — offline manuals, READMEs, printable guides  
- **Desktop UX v1** — consistent UI across all modules  

---

# **2. 6‑Month Roadmap — Expansion Phase**

- **Multi‑App Session Sync** — share mnemonic, seed, and path context across apps without re‑entering  
- **Guided Recovery PRO** — multi‑step recovery with automatic tool chaining  
- **Wallet Preset Auto‑Detection** — detect wallet type from mnemonic, xpub, or address  
- **Desktop Notifications** — progress indicators, warnings, cross‑app alerts  
- **Suite‑Wide Export Module** — export reports, paths, and diagnostics  
- **UX Enhancements** — smoother navigation, improved layout, accessibility improvements  

---

# **3. 12‑Month Roadmap — PRO Phase**

- **Hardened Mode PRO** — no disk writes, secure memory handling, ephemeral sessions  
- **Cross‑App Automation Engine** — run multi‑tool workflows automatically (e.g., Forensics → Recovery → Export)  
- **Suite‑Wide Interoperability Layer** — shared engines, shared presets, unified data formats  
- **Mixed‑Wallet Detection** — detect wallets using multiple BIP standards  
- **Desktop PRO Dashboard** — advanced analytics, session summaries, forensic indicators  
- **Reproducible Builds** — deterministic builds + verification instructions  

---

# **Long‑Term Vision**

SeedTools Desktop becomes the **primary offline environment** for deterministic Bitcoin recovery and forensics:

- unified UX across all apps  
- trusted by NGOs and support teams  
- safe for high‑risk users  
- fully offline and auditable  
- reproducible and verifiable  
- the flagship interface of the SeedTools Suite
