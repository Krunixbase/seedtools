# **Path Explorer — Roadmap**

## **Overview**

This roadmap defines the development plan for Path Explorer over the next 12 months.  
The focus is on deep derivation‑path exploration, custom path building, extended index scanning, visualization, wallet interoperability, and integration with Address Scanner and Recovery Tool.

---

# **1. 3‑Month Roadmap — Foundation Phase**

- **BIP Standard Engine v1** — support for BIP32/44/49/84/86, hardened segment parsing, path validation  
- **Custom Path Builder MVP** — interactive path creation, syntax validation, error detection  
- **Address Generation Engine** — derive keys and addresses for any valid path  
- **Deep Index Scan MVP** — extended index scanning, change 0/1 support  
- **Documentation v1** — workflows, examples, architecture  

---

# **2. 6‑Month Roadmap — Expansion Phase**

- **Multi‑Account Auto‑Detection** — detect multiple accounts automatically  
- **Taproot Path Analysis** — BIP86‑specific path validation, mismatch detection  
- **Path Visualization Graph** — hierarchical tree view of derivation paths  
- **Wallet Presets** — Sparrow, Specter, Electrum, BTCPay‑style, hardware‑wallet‑like patterns  
- **UX Enhancements** — better layout, clearer warnings, interactive path components  
- **Export Module** — export paths, keys, and addresses for external tools  

---

# **3. 12‑Month Roadmap — PRO Phase**

- **Deep Scan Engine PRO** — multi‑account scanning, extended index ranges, performance optimization  
- **Mixed‑Type Wallet Detection** — detect wallets using multiple BIP standards  
- **High‑Risk Safe Mode** — offline‑only, no‑disk‑write, secure memory handling  
- **Interoperability Layer** — compatibility with wallet metadata formats  
- **Integration with Address Scanner** — automatic path extraction during address scanning  
- **Reproducible Builds** — deterministic builds + verification instructions  

---

# **Long‑Term Vision**

Path Explorer becomes the **standard offline derivation‑path analysis tool** for Bitcoin:

- trusted by developers and wallet maintainers  
- used by NGOs and support teams  
- safe for high‑risk users  
- fully auditable and reproducible  
- maintained as a long‑term public good
