# **Recovery Tool — Roadmap**

## **Overview**

This roadmap defines the development plan for the Recovery Tool over the next 12 months.
It focuses on deterministic recovery, deep path scanning, wallet interoperability, UX improvements, and high‑risk user workflows.

---

# **1. 3‑Month Roadmap — Foundation Phase**

- **Deterministic Engine v1** — stabilize BIP32/39/44/49/84/86, extended index scanning, path validation
- **Recovery Mode MVP** — guided workflows, passphrase handling, address verification
- **Auto‑Detect Paths** — detect BIP standards and common wallet structures
- **Address Verification Engine** — match detection, path extraction, type identification
- **Documentation v1** — basic workflows, architecture, examples

---

# **2. 6‑Month Roadmap — Expansion Phase**

- **Taproot Support (BIP86)** — scanning, address verification, path presets
- **Deep Scan Engine** — extended index ranges, multi‑account scanning, performance improvements
- **Wallet Presets** — Sparrow, Specter, Electrum, BTCPay‑style, hardware‑wallet‑like patterns
- **Batch Address Verification** — verify multiple addresses at once
- **UX Enhancements** — onboarding, error handling, progress indicators
- **Export Module** — export paths, addresses, indexes for external wallets

---

# **3. 12‑Month Roadmap — PRO Phase**

- **Recovery Mode PRO** — advanced diagnostics, wrong‑path detection, wrong‑index detection
- **Multi‑Account Recovery** — detect and reconstruct multiple accounts automatically
- **High‑Risk Safe Mode** — offline‑only, no‑disk‑write, secure memory handling
- **Interoperability Layer** — compatibility with wallet metadata formats
- **Reproducible Builds** — deterministic builds + verification instructions
- **NGO / Support Toolkit** — field‑safe workflows, printable guides, demo packs

---

# **Long‑Term Vision**

Recovery Tool becomes the **standard offline recovery workflow** for Bitcoin:

- deterministic, auditable, transparent
- compatible with all major wallets
- safe for high‑risk users
- trusted by NGOs and support teams
- maintained as a long‑term public good
