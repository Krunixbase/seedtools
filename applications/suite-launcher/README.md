# **Suite Launcher — SeedTools Suite**

## **Overview**

Suite Launcher is the **central entry point** for the entire SeedTools Suite.  
It provides a unified, offline‑first interface that allows users to launch all applications, manage presets, access documentation, and run guided workflows.

Suite Launcher is designed to:

- simplify navigation across all SeedTools apps,  
- provide consistent UX and shared components,  
- offer guided flows for recovery, forensics, scanning, and analysis,  
- support NGOs and high‑risk users with fast, safe access to tools,  
- unify the Suite into a single, coherent product.

It is the **home screen** of SeedTools.

---

# **Key Capabilities**

- **Unified App Launcher**  
  - open any SeedTools application  
  - consistent UI across the Suite  
  - offline‑first navigation  

- **Guided Workflows**  
  - Recovery Mode  
  - Forensics Mode  
  - Address Verification Mode  
  - Entropy/Mnemonic Diagnostics  

- **Preset Manager**  
  - wallet presets (Sparrow, Specter, Electrum, BTCPay)  
  - BIP standard presets  
  - NGO‑friendly presets  

- **Suite‑Wide Settings**  
  - theme  
  - language  
  - security mode (offline‑only, hardened mode)  

- **Documentation Hub**  
  - access all READMEs  
  - offline manuals  
  - printable guides  

- **Offline‑First Architecture**  
  - no telemetry  
  - no external API calls  
  - safe for air‑gapped devices

# **Typical Workflows**

## **1. Launch any SeedTools application**

1. Open Suite Launcher.  
2. Choose an app:
   - Recovery Tool  
   - Forensics Tool  
   - Address Scanner  
   - Entropy Inspector  
   - Mnemonic Tools  
   - Path Explorer  
   - SeedTools CLI  
3. App opens in a unified, consistent UI.

---

## **2. Use a guided workflow**

Suite Launcher includes guided flows for:

- **Recovery Mode**  
- **Forensics Mode**  
- **Address Verification Mode**  
- **Mnemonic/Entropy Diagnostics**

Example:

1. Select **Recovery Mode**.  
2. Launcher asks:
   - mnemonic  
   - passphrase  
   - wallet type  
3. Launcher automatically opens the correct tools in sequence.

---

## **3. Manage presets**

1. Open **Preset Manager**.  
2. Choose:
   - BIP standard  
   - wallet type  
   - NGO preset  
3. Preset is applied across all apps.

---

## **4. Access documentation**

1. Open **Documentation Hub**.  
2. Browse:
   - app READMEs  
   - offline manuals  
   - printable guides  
3. Everything works offline.

# **Security Notes**

- Suite Launcher should be used on a **trusted machine**.  
- Hardened Mode disables:
  - disk writes  
  - logs  
  - caching  
- No telemetry or analytics are ever used.  
- Verify builds using reproducible build instructions.
