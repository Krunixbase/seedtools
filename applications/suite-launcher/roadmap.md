# **Suite Launcher — Roadmap**

## **Overview**

This roadmap defines the development plan for Suite Launcher over the next 12 months.  
The focus is on unified navigation, guided workflows, cross‑app session sync, hardened security modes, wallet presets, and deep integration across the entire SeedTools Suite.

---

# **1. 3‑Month Roadmap — Foundation Phase**

- **Launcher Core Engine v1** — unified navigation, offline‑first architecture, secure app loading  
- **Guided Workflows MVP** — Recovery Mode, Forensics Mode, Address Verification Mode  
- **Preset Manager v1** — BIP standards, wallet presets, NGO presets  
- **Documentation Hub MVP** — access to all READMEs and offline manuals  
- **Suite‑Wide Settings** — theme, language, offline mode  
- **Launcher UX v1** — consistent UI across all apps  

---

# **2. 6‑Month Roadmap — Expansion Phase**

- **Cross‑App Session Sync** — share mnemonic, seed, and path context across apps without re‑entering  
- **Guided Recovery PRO** — multi‑step recovery with automatic tool chaining  
- **Wallet Preset Auto‑Detection** — detect wallet type from mnemonic, xpub, or address  
- **Launcher Notifications** — progress indicators, warnings, cross‑app alerts  
- **Suite‑Wide Export Module** — export reports, paths, and diagnostics  
- **UX Enhancements** — smoother navigation, improved layout, accessibility improvements  

---

# **3. 12‑Month Roadmap — PRO Phase**

- **Hardened Mode for NGOs/High‑Risk Users** — no disk writes, secure memory handling, ephemeral sessions  
- **Cross‑App Automation Engine** — run multi‑tool workflows automatically (e.g., Forensics → Recovery → Export)  
- **Suite‑Wide Interoperability Layer** — shared engines, shared presets, unified data formats  
- **Mixed‑Wallet Detection** — detect wallets using multiple BIP standards  
- **Launcher PRO Dashboard** — advanced analytics, session summaries, forensic indicators  
- **Reproducible Builds** — deterministic builds + verification instructions  

---

# **Long‑Term Vision**

Suite Launcher becomes the **central nervous system** of the entire SeedTools Suite:

- unified UX across all apps  
- trusted by NGOs and support teams  
- safe for high‑risk users  
- fully offline and auditable  
- reproducible and verifiable  
- the default entry point for deterministic Bitcoin recovery and forensics
